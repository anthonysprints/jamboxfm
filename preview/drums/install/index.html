AFTER THE INSTRUMENT RETURNS

      
A quick drum workflow check.

      
    
        
  1. Check your saved jam. Start at low volume. Confirm your existing loop, tempo and edited sounds returned. Do not reinitialize saving.
    2. 
        
  2. Go directly to drums. Select Drums, then tap SEQ once. The drum GRID should open immediately.
    3. 
        
  3. Build a beat. Knob 1 chooses a drum; the named rows follow it. White keys switch its steps on and off. Knob 2 chooses a step, knob 3 changes its strength, and knob 4 adds repeated hits. Empty cells stay empty until you add a hit.
    4. 
        
  4. Check the main knobs. SELECT changes BPM, PRESETS chooses a kit, and ALGORITHM switches parts in the same order as Home.
    5. 
        
  5. Check GRID and KIT. SEQ opens or keeps GRID. EDIT switches GRID/KIT. Try a later step page and held SEQ, then check that the same drum and page return.
    6. 
        
  6. Return HOME and record. HOME returns to your previous GROOVE or SOUND view. REC from GRID also returns Home, so the keys play drum sounds while you record. Check Bass, Chords and Lead SEQ screens too.
    7. 
      

      
Report any unexpected screen, button, sound or light behavior. The install response confirms firmware identity, not the physical workflow. Use Save now only when you want to replace your saved checkpoint.

      
Drum grid controls
Drum / Step / Strength / Repeat are the four right knobs. Strength goes from ghost to hard; Repeat gives 1–4 hits within a step. The first four black keys select step pages. The grid stays on your editing page while playback continues. SELECT controls tempo in GRID and KIT; held shortcuts keep their own labelled controls. Individual drum sound editing comes in a later stage.
